Aduna for Windows. Windows and your browser will show a couple of warnings because Aduna is new. Here is what to click.

Download again Didn’t start? Click the button above.
Aduna is new and not yet signed with a paid Microsoft certificate, so Chrome and Windows warn about it. Only continue if you got this installer from this page.

  1. If your browser asks, click “Keep”

    Chrome may say the file “is not commonly downloaded”. Click Keep. In Edge, open the downloads list, open the “…” menu next to the file and choose Keep.

  2. Open the file, then click “More info”

    Open Aduna-Setup from your Downloads. When Windows says it protected your PC, click More info (the small link, not the big button).

  3. Click “Run anyway”

    The Run anyway button appears after More info. Click it and Aduna installs in a few seconds.

  4. You’re in

    Aduna opens when it finishes and adds a shortcut to your desktop and Start menu. After this, updates install from inside the app without these warnings.

Your download is starting

Aduna for Android. Android will ask you to approve a couple of things because Aduna is not from the Play Store yet. Here is what to tap.

Download again Didn’t start? Tap the button above.
Only install this file if you got it from this page.

  1. If Chrome warns about the file, tap “Download anyway”

    Chrome says this type of file can harm your device. Tap Download anyway (or Keep).

  2. Open the file

    Tap Open when the download finishes, or open Aduna.apk from your Downloads.

  3. Allow installs from this source

    Android will say it can’t install unknown apps from Chrome. Tap Settings, switch on Allow from this source, go back and tap Install. If Play Protect warns you, choose Install anyway.

  4. You’re in

    Open Aduna from your home screen. The app loads the live site, so updates arrive by themselves.

Aduna on this device

The installer is for Windows computers and the app for Android phones. On this device you can use Aduna right in your browser, or add it to your home screen or apps.

Open Aduna

  1. Chrome or Edge on a computer or Android

    Open Aduna, then click the install icon at the right of the address bar, or open the browser menu and choose Install Aduna.

  2. iPhone or iPad

    Open Aduna in Safari, tap the Share button, then Add to Home Screen.
